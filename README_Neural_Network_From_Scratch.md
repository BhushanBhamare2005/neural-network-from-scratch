# Neural Network From Scratch — Generative AI Lab

## Project
A feedforward neural network for Iris multi-class classification implemented from scratch using NumPy.

## Architecture
- Input: 4 features
- Hidden: 8 neurons + ReLU
- Output: 3 neurons + Softmax
- Loss: Categorical Cross-Entropy
- Optimizer: Batch Gradient Descent

## Requirements
```bash
pip install numpy pandas matplotlib scikit-learn jupyter
```

## Run
```bash
jupyter notebook Bhushan_Bhamare_GenerativeAILabAssignment.ipynb
```

Run all cells sequentially before submission.

## Academic note
The neural-network computations are implemented manually. `scikit-learn` is used only to provide the standard Iris dataset.
